ACCOUNT REGISTRATION - WINDOWS FORMS

1. Open "Account Registration.sln" in Visual Studio 2015 or later.
2. If Visual Studio asks to retarget .NET Framework 4.6.1, choose an installed .NET Framework version.
3. Build the solution, then press F5.
4. Both forms can be edited with the Windows Forms Designer.

Project files:
- FrmRegistration.cs / FrmRegistration.Designer.cs
- FrmConfirm.cs / FrmConfirm.Designer.cs
- StudentInfoClass.cs
- Program.cs

Note: The exercise requires FormClosing to return DialogResult.OK, so closing the confirmation window also clears the registration form.
